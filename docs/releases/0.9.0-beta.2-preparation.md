# App 0.9.0-beta.2 release preparation

Prepared 2026-09-29 for `app-v0.9.0-beta.2`, the second beta on the way to 0.9.0 ([DR-087](../../specs/decisions/087-beta-app-releases.md)), covering desktop and server as source.
A beta gates on CI, the smoke and the live smoke, and runs neither the regression nor the manual checklist ([release-26](../../specs/packages/release.md#release-26)).
The [release rules](../../specs/packages/release.md) remain the gate authority.

## Review

Since `app-v0.9.0-beta.1` the range adds one change: readiness names what Cligent finds missing ([DR-090](../../specs/decisions/090-readiness-names-what-cligent-finds-missing.md)), merged as `7dd1f6e`.
An agent whose SDK's native binary npm dropped — an optional platform package — read ready and failed at its first run; readiness now reads it not ready, naming the package and the repair, from Cligent 0.27.1's own lookup, so Spex holds no SDK layout rule.
The core's Cligent floor moves to `^0.27.1`, which the lockfile resolves.
The changelog's `[Unreleased]` section carries the entry; as for every beta, it gains no section of its own, so this beta's notes are that section at the tag, beta 1's notes included ([release-27](../../specs/packages/release.md#release-27)).

## Upgrade boundaries

Those of `app-v0.9.0-beta.1` stand ([its record](0.9.0-beta.1-preparation.md)); this beta adds the Cligent 0.27.1 floor.
