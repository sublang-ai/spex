# App 0.9.0-beta.3 release preparation

Prepared 2026-09-29 for `app-v0.9.0-beta.3`, the third beta on the way to 0.9.0 ([DR-087](../../specs/decisions/087-beta-app-releases.md)), covering desktop and server as source.
A beta gates on CI, the smoke and the live smoke, and runs neither the regression nor the manual checklist ([release-26](../../specs/packages/release.md#release-26)).
The [release rules](../../specs/packages/release.md) remain the gate authority.

## Review

Since `app-v0.9.0-beta.2` the range adds the betas' publication record and one merge, `5379860`, of two changes:

- Models named by the runtime ([DR-091](../../specs/decisions/091-models-named-by-the-runtime.md)): the model field is a listbox naming each model the runtime's way — its name, the specific model behind it and the runtime's own description — the provider default names the model the runtime selects, and an agent's chip reads the model its runtime reported for its latest call while its adapter and model setting stand.
  The seeds, the demo configuration and the scaffold's trailer example name the latest models.
- The released toolchain ([DR-092](../../specs/decisions/092-playbook-17-1-slc-0-13-cligent-0-28-adoption.md)): the core requires Cligent `^0.28.0` and Playbook `^17.1.0`, and both shells slc `^0.13.0`, so one engine and one Cligent serve the app and its compiler; the lock holds Claude Agent SDK 0.3.284, Codex SDK 0.159.0 and OpenCode SDK 1.18.33.

The changelog's `[Unreleased]` section carries the entries; as for every beta, it gains no section of its own, so this beta's notes are that section at the tag, the earlier betas' notes included ([release-27](../../specs/packages/release.md#release-27)).

## Upgrade boundaries

Those of `app-v0.9.0-beta.2` stand ([its record](0.9.0-beta.2-preparation.md)); this beta adds Cligent 0.28's runtime floors.
An agent runtime older than the oldest release serving its provider's latest models — Claude Agent SDK 0.3.284, Codex 0.156.1, OpenCode 1.18.29 or Gemini CLI 0.61.0 — reads not ready, naming its upgrade.
The app's own locked SDKs meet the Claude, Codex and OpenCode floors; an OpenCode or Gemini CLI on the `PATH` may need upgrading.

## Coverage this release does not have

The regression is not a beta gate, and it was not run for this beta.
Beta 1 recorded two regression blockers: the provider's refusal of the Captain's judge calls on the template's `claude-opus-5`, which the template no longer names — it now names `claude-opus-5-5` — so that blocker is untested rather than known to stand; and [sublang-ai/slc#29](https://github.com/sublang-ai/slc/issues/29), still open against slc 0.13.0.
