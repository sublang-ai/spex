# Fork rebase: 0.9.0-beta.21

This Fork beta incorporates official upstream main through
`176570815866d2c671e187cb0929de8ebd1233a9` and retains the verified native
Windows and installer changes. The official Space and CLI changes are
preserved. Native Windows decision records use DR-178 and DR-179 to avoid
collisions with upstream DR-171 and DR-172.

The release workflow requires green CI, builds the tagged source on native
macOS and Windows runners, and publishes both installer hashes together.
The app remains unsigned and the macOS build is not notarized.

The owner-requested local acceptance is to clean only previous test state,
install the actual published DMG and EXE, and complete one built-in inspect
on each computer with real agents. Windows must use the current Mac's
ChatGPT login and a network proxy through that Mac. Private-storage and
execution permissions remain in force. Installing the acceptance Skill,
merging main and submitting an upstream PR are outside this round.

This preparation record describes the scope; it does not claim that the
future published installers have already passed local acceptance.
