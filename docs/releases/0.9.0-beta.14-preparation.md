## Changes since beta.13

Beta.13 was released at `c92e817c`; its preparation record and smoke results remain historical evidence for that release.
The candidate contains four implemented reliability fixes and the subsequent dependency adoption:

- PR185 (`40e14cac`): the new package tree's committed rename remains successful if obsolete-tree cleanup fails, so installation and exports agree; precommit failures retain restoration and the primary error.
- PR186 (`dc510b53`): session-list replies preserve newer session announcements and reject stale connection/read generations, preventing stale working state from blocking the composer.
- PR187 (`3ebddc53`): Sync refuses unsafe destination parents, retains partial records and repair evidence on late refusal, and defers unsafe refresh until repair.
- PR188 (`fc0b4292`): storage validation checks actual read/delegation boundaries without following unsafe paths, preserves Playbook's session and asset validation authority, and names the expected path to repair.

- PR182 (`6dddd2be`): adopt Playbook 17.11.0, Cligent 0.36.0 and slc 0.19.0, retaining the locked agent SDKs; read export folders from Cligent's published native-skill support. Captain control and compiler calls disable native skill discovery as far as each adapter permits, while working players and authoring sessions retain it ([DR-130](../../specs/decisions/130-playbook-17-11-0-cligent-0-36-0-slc-0-19-0-adoption.md)). Kimi has no per-run switch; an agent that offers the switch but cannot apply it fails rather than silently retaining discovery. Existing Captain conversations can retain earlier listings; this adoption does not recompile artifacts, update environment locks or claim a session-store migration.

The app changelog's nonempty `[Unreleased]` remains the beta's cumulative notes, with no beta-specific version section.
Earlier specification-only proposals are not newly implemented features of this beta.
