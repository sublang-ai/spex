# App 0.9.0-beta.19 release preparation

Preparation began on 2026-10-29. Publication remains pending.
The intended tag is `app-v0.9.0-beta.19`, a source-only pre-release titled `Spex App v0.9.0-beta.19`.

## Scope

[DR-167](../../specs/decisions/167-the-compiler-shares-the-apps-engine.md) withdraws the compiler-only nested Playbook exception.
Both shells adopt slc 0.20.0 and directly supply Playbook 18.1.0 through compatible caret declarations.
The compiler declares Playbook as a required peer; its exact development reference remains its own release provenance.
Spex verifies one locked and physical installation of Playbook, Cligent and xstate, dependency metadata and ranges, and actual resolution from both shells, the core and compiler.
Its artifact integration check provisions and bundles TypeScript, verifies engine identity, and executes the real Playbook runtime to a terminal outcome.
The runtime ABI/schema guard remains in place.

The release preserves the app's Cligent 0.36.1, xstate 5.33.3 and agent SDK resolutions.
The separately versioned scaffold CLI and compiler grammar dependencies retain their ordinary dependency relationship.
The app changelog retains its non-empty `[Unreleased]` section for the beta.

slc 0.20.0 was published from `acaee3fae6cf902c33961d006d7cff139b3c7007` by successful [release run 41008999766](https://github.com/sublang-ai/slc/actions/runs/41008999766).
Registry metadata confirms its required Playbook `^18.1.0` peer, exact 18.1.0 development reference and source commit.
npm generated the app lock from the public registry: slc changes from 0.19.1 to 0.20.0 and its nested Playbook 17.11.1 is removed.
All 836 other installed-package version, resolved URL and integrity fingerprints match the preceding app lock.

## Verification

The dependency suite passes all 19 cases: 16 isolated fixtures, the installed app closure, and real bundled artifact execution through each shell.
The fixtures include duplicate engines with identical versions, stale metadata, incompatible peers and an unlocked nested compiler.
The clean registry `npm ci`, dependency gate and `npm run prepush` pass.
Pre-push includes the workspace build, catalog validation, spec lint and e2e type checks; lint has zero errors and the pre-existing `core-service-41` advisory.
The version check accepts both shell manifests as 0.9.0-beta.19.
The installed smoke and remote CI are pending.

## Publication

The final tag requires a successful CI run on its exact main commit and the installed smoke, including real agent output, abort and cleanup.
The regular-release regression and manual checklist are not beta gates under [release-26](../../specs/packages/release.md#release-26); neither is claimed here.
The normal App Release workflow must pass before publication is recorded as complete.
