# App 0.9.0-beta.19 release preparation

Preparation began on 2026-10-29. The owner subsequently clarified that app publication is not required for this dependency fix.
slc 0.20.0 is published and the Spex dependency change is merged; no app tag or release was created.
The prepared version remains `0.9.0-beta.19` for a possible future source-only app pre-release.

## Scope

[DR-167](../../specs/decisions/167-the-compiler-shares-the-apps-engine.md) withdraws the compiler-only nested Playbook exception.
Both shells adopt slc 0.20.0 and directly supply Playbook 18.1.0 through compatible caret declarations.
The compiler declares Playbook as a required peer; its exact development reference remains its own release provenance.
Spex verifies one locked and physical installation of Playbook, Cligent and xstate, dependency metadata and ranges, and actual resolution from both shells, the core and compiler.
Its artifact integration check provisions and bundles TypeScript, verifies engine identity, and executes the real Playbook runtime to a terminal outcome.
The runtime ABI/schema guard remains in place.

The release preserves the app's Cligent 0.36.1, xstate 5.33.3 and agent SDK resolutions.
The separately versioned scaffold CLI and compiler grammar dependencies retain their ordinary dependency relationship.
The app changelog retains its non-empty `[Unreleased]` section for the beta.

The first combined-candidate smoke passed installation and the server walk, then failed because the official Electron download did not complete within the desktop stage's ten-minute budget.
This is the same download issue recorded for [CLI 4.2.0](cli-4.2.0-preparation.md#the-first-smoke-run).
Electron 44.0.0's official Darwin arm64 archive was recovered using a copied partial download and verified byte ranges from the same official URL.
Its size is 129,743,965 bytes and SHA-256 is `076d79742986e1b100b69ebecc691cb07368045e54c9087cef631b8622b76a80`, matching the installed Electron package's pinned checksum.
The archive was placed through `@electron/get`'s own cache API; its ordinary artifact lookup then verified it with network access disabled.
The replacement smoke uses `electron_config_cache=/private/tmp/spex-electron-cache` for this invocation only, keeps its npm cache empty and runs the unchanged committed source and smoke driver.
It reuses the completed build and lint with `--from=fresh-install`; every remaining stage, including the real installed live stage, runs again.
The replacement exits zero: fresh install 2 minutes 7 seconds, CLI user pass 9 seconds and installed live stage 49 seconds.
It observes real coder output, completes abort and session cleanup, exits the desktop, and restores the Node ABI.
No provider waiver or smoke assertion change is used.
The passing smoke log SHA-256 is `10d857c41fc39f6166b36fb33d3cf24af992307d78a98d8dddefc5db7ec91ae9`.
The combined-candidate pre-push log SHA-256 is `5fd718610a6247eae2de734c12d70499ee4239d9342cdc0380411b066b7d0fbd`; the 19-test dependency log SHA-256 is `a247262218ce53e097a2fbe70e8cbee6f9b3e657d8476b2c43212cc9bffe0925`.
