## Upgrade boundaries

The sidebar's "Workspace" reads "Projects" on screen only: the surface value,
state keys and test ids keep their internal names, so no stored preference or
session key changes.

Space syncs one shared branch, `main`, in the Spex home and needs `git` on
`PATH`; the core runs every Git step itself, never through a shell, and never a
Git merge. A home with no remote stays local until Initialize or Join. Joining
an unrelated history requires the explicit join; the per-unit picker resolves
what changed on both sides.

Playbook drafts live under `local/drafts/<id>/` in the Spex home and are not
registered playbooks until Register is pressed.

Playbook 13.2 or later is required: issue delivery uses its `branch` and `pr`
built-ins and its issue-aware `dev`. Existing queued intents keep their text;
newly queued issues carry the `/dev` seed.

The protocol version is 11. A page served from an older UI bundle refuses to
connect to this core, and this UI refuses an older core; run both shells from
the same source tree.
