# App 0.9.0-beta.7 release preparation

Prepared 2026-10-01 for `app-v0.9.0-beta.7`, the seventh beta on the way to 0.9.0 ([DR-087](../../specs/decisions/087-beta-app-releases.md)), covering desktop and server as source.
A beta gates on CI, the smoke and the live smoke, and runs neither the regression nor the manual checklist ([release-26](../../specs/packages/release.md#release-26)).
The [release rules](../../specs/packages/release.md) remain the gate authority.

## Review

Since `app-v0.9.0-beta.6` the range adds the beta's publication record, a correction of its notes and of DR-095's links, and one merge of change found by walking beta 6 as a fresh user over a fresh home:

- An item's Edit control opened the package file with the caret on the item's heading but scrolled by logical lines, so in a file whose long lines soft-wrap the heading landed below the visible box — `run-view.md` opened on run-view-147 for run-view-4.
  The landing now measures the heading's rendered offset, soft wraps counted ([spec-view-48](../../specs/packages/spec-view.md#spec-view-48)), and the spec-view-54 journey asserts the heading inside the field's box on the demo's longest package, failing on the former editor.

The same walk filed what it did not fix as [sublang-ai/spex#29](https://github.com/sublang-ai/spex/issues/29) to [#33](https://github.com/sublang-ai/spex/issues/33): a clone's History all "just now", no copyright holder pinned at project creation, `spex lint` absent from a desktop-only PATH, the former store re-imported into every new home, and the seeded model pin reading as a duplicate row.

The changelog's `[Unreleased]` section carries the entry; as for every beta, it gains no section of its own, so this beta's notes are that section at the tag, the earlier betas' notes included ([release-27](../../specs/packages/release.md#release-27)).
