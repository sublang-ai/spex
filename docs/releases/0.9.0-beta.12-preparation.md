## Range review

The range since beta.11 (`6cf9137f0141c61ceb75c228cfd4a2fd1863164a`) contains one commit:

- `f598c192`: Expose full Groups refresh lifecycle (PR175).

Groups tracks Refresh through account setup and the complete read, publishes a safe success or failure outcome, and keeps Retry available after failure.
Repeated refreshes join work for the same account generation; a refresh accepted after sign-out or sign-in waits for older work and then reads the current account.
An older completion cannot settle the newer account's lifecycle, and a destination-only read keeps its separate authority.
The UI exposes the running state accessibly and keeps the last complete view when a read fails.
The notable fix is recorded in `[Unreleased]`, which remains the beta's notes.

The original signed implementation commit is `c3e8e87ec3bd28fb1f50d4f5d7b0a7f927d1e180`.
The accepted rebase result `f598c192` has the same reviewed tree and is unsigned; the original signed source is preserved separately.
PR175 passed all nine CI jobs on its reviewed source.
No automatic main CI run was observed for `f598c192` in the retained bounded observations; its cause is unknown.
Neither that PR result nor beta.11's CI supplies the final tag commit's gate.
