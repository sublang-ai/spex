## Compatibility

- Playbook remains 17.10.1, with one Cligent and one slc and no dependency overrides; the existing agent SDK locks are unchanged.
- The built-in spec package remains 17.10.1; existing environment locks are not silently updated and session-store writer coordination remains the installed runtime's contract.
- Configuration holding a `skills` list is refused with its entry named; skills instead reach agents through the spec packages their environments install.
- A schema-3 playbook with required options emitted by slc 0.16.1 must be recompiled to receive the correct configured option slice.
- The Codex raw-separator protection is POSIX-only; native Windows keeps its existing no-policy path and policy rejection.
- No session-store or protocol format change is introduced by this version preparation.
