# App 0.9.0-beta.25 release preparation

Preparation recorded on 2026-11-03. This record distinguishes completed local
checks from pending release gates; no tag or installer is claimed in advance.
The intended tag is `app-v0.9.0-beta.25`, an app pre-release with native macOS
Apple Silicon and Windows x64 installers.

[PR 344](https://github.com/sublang-ai/spex/pull/344) merged as
`1bc42acd11ad5d8ab4c006342ed60f7bc2666454`; its complete source tree matches the
locally accepted signed candidate `3acf6c3d52b523f40ce4fd2d39b274bef7b62e1f`.

passed its required `checks` gate, including selected Linux and Windows suites.

The fix preserves production declarations before archive filtering, reuses the
existing unpacked-path rule for authoring documents, esbuild and default engine
links, and gates each native package on the actual supplied strict checker,
native bundler, engine links and imported registry output. No compiler/runtime
business logic, external dependency upgrade or weakened type checking is added.

The official commits since the previous official app release were reviewed.
Their notable changes remain in the app changelog's non-empty `[Unreleased]`
section, including Workshop agent cards, independent registries, package
publishing, group management and the shared runtime adoption. This preparation
changes only both shell versions, their lock entries and release records/notes.

and electron-builder 26.15.3 remain the upstream-locked versions.

Focused runtime tests (25), environment integration tests (20), release workflow
tests (6) and prepush passed. Spec lint had zero errors and one preexisting
core-service-41 sentence advisory.

unchanged; the current installed APP was not overwritten. Screenshots and logs
are retained in the owner's isolated acceptance evidence directory.

## Limits

Real UI acceptance so far covers Mac, Codex and explicit ESM projects only.
SLC 0.20.1's native ESM loader still rejects an explicit CommonJS package scope;
that independent behavior was reproduced against SLC 0.20.0 as well and is not
changed in this packaging repair. No other Agent's authenticated call, Windows
real UI flow or testing Skill full workflow is claimed. Raw U+2028/U+2029 SDK
output remains the previously accepted runtime limitation. Installer signing
and macOS notarization remain outside the existing native-release contract.
