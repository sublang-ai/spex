# App 0.9.0-beta.6 release preparation

Prepared 2026-10-01 for `app-v0.9.0-beta.6`, the sixth beta on the way to 0.9.0 ([DR-087](../../specs/decisions/087-beta-app-releases.md)), covering desktop and server as source.
A beta gates on CI, the smoke and the live smoke, and runs neither the regression nor the manual checklist ([release-26](../../specs/packages/release.md#release-26)).
The [release rules](../../specs/packages/release.md) remain the gate authority.

## Review

Since `app-v0.9.0-beta.5` the range adds the beta's publication record and one merge of change, a subagent's effort and the agent's own model by default ([DR-095](../../specs/decisions/095-a-subagents-effort-and-the-agents-own-model.md)):

- The subagent-model field offers "Same as agent" first and by default, then the adapter's models; a configured `false` reads "Off" only while it stands.
  A fifth tuning field, the subagent effort, offers "Agent chooses" first and by default, then the adapter's efforts; both have the tri-state of the other tuning fields at every tier and are applied at the three sites of DR-067.
- Each model and its effort share one row in the shared agent editor, the role-binding editor and the session agent editor; the pairs stack at the 320-pixel floor.
- Cligent 0.30 enforces and phrases it: `inherit` binds every subagent to the agent's own model, a pinned effort registers delegate definitions at that effort (and replaces `general-purpose` with one), an omitted effort registers one per effort for the agent to choose, and the directive's first sentence follows the two; Playbook 17.3 carries the effort as tuning and resolves an unset subagent model to `inherit` where the adapter serves one, so every Claude agent delegates by default; slc 0.15 declares both.
  The core requires Cligent `^0.30.0`, Playbook `^17.3.0` and both shells slc `^0.15.0`.

The changelog's `[Unreleased]` section carries the entries; as for every beta, it gains no section of its own, so this beta's notes are that section at the tag, the earlier betas' notes included ([release-27](../../specs/packages/release.md#release-27)).

## Upgrade boundaries

Those of `app-v0.9.0-beta.5` stand ([its record](0.9.0-beta.5-preparation.md)); this beta adds two.
Every Claude agent of an existing configuration now delegates by default — its runs carry the directive and the subagent definitions, on its own model at efforts of the agent's choosing — and the subagent-model field's "Off" (`subagentModel: false`) is the way back.
A session record that carries a subagent effort cannot be opened by Playbook 17.2 or earlier, so every host sharing a Spex home upgrades together.
