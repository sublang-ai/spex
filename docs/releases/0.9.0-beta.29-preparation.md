# App 0.9.0-beta.29 release preparation

This beta adopts Playbook 18.2.0 on top of official main `0522828a`.
The `app-v0.9.0-beta.28` tag never published (its macOS package job found no runner), so this release's notes span from beta.27, the previous published app release.
`node scripts/release-version.mjs check --tag=app-v0.9.0-beta.29` accepts the tag, and no `app-v0.9.0-beta.29` tag or release exists.

## Scope

- `e096afdf build(deps): Take Playbook 18.2.0`: Playbook `^18.2.0` in the core, both shells and the root tooling; the lock changes only in Playbook's entry, with one shared Playbook 18.2.0, Cligent 0.38.0 and xstate 5.33.3; the built-ins stage as `sublang/playbooks` 18.2.0.
- The captured `code` and `review` machine fixtures were recaptured, and the demo and UI tests name CODE's one review state `reviewIntent`.
- No spex source reads REVIEW's output interface or Playbook's failure codes beyond `aborted`, which the failure catalogue already words, so no product code changed.
- The CLI (`@sublang/spex`) does not depend on Playbook, so no CLI release is part of this adoption.
