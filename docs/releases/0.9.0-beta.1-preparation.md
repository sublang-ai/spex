## Upgrade boundaries

- Playbook 17 moves the session store forward: once this build saves a session, a host on Playbook 16 or older — a `playbook` CLI sharing the Spex home, or another device syncing it through Space — cannot open that session. Upgrade every host sharing the home together, and snapshot the home first ([DR-050](../../specs/decisions/050-shared-storage-cutover.md)).
- A session parked on a question inside a built-in state that Playbook 16 renamed no longer resumes from the answer; Drop it or send a new request.
- The protocol moves from version 11 to 17, and the app requires Node.js 22.19 or later.

## Coverage this release does not have

The regression is not a beta gate.
Its recorded runs, in the fresh-user scenarios' intent record, met two blockers that stand at this tag:

- The provider refused the Captain's judge calls on the template's `claude-opus-5` ("Opus 5's safeguards flagged this message … `[reasoning_extraction]`"), stopping both the new-project walk and the authored playbook's run.
- slc 0.12 refused the app's own example at its machine phase on every compile so far ([sublang-ai/slc#29](https://github.com/sublang-ai/slc/issues/29)), so the compiled-fixture journey skips and the example card's later stages remain the original demo's.
