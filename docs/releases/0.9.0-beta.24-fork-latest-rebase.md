## Native CI timeout diagnosis

The initial Fork Windows CLI lane completed 213 assertions but its package-command file reached the existing 180-second whole-file deadline before its final cause matrix finished.
The same unmodified file on a personal Windows host ran for 464 seconds under a diagnostic 600-second budget: 18 cases passed and the last case reached an exact-stderr assertion, where the expected refusal text was accompanied by the supported fs-safe fallback warnings.
The Windows CLI runner therefore uses a bounded 600-second file budget; other hosts keep 180 seconds, every assertion and forced-exit cleanup remain, and no application code changes.
That assertion preserves the three recognized Windows fallback warnings in the test log while still checking every other stderr byte, the refusal exit code and the unchanged files; no global warning suppression or product behavior is changed.
